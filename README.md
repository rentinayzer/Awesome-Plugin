# ! Активация Плагина
В VSCode открыть папку с плагином и нажать F5 и в открытом extension development host-е активируется плагин.

---
# 1й уровень - База.
В базе имеется сама основа плагина, и самое главное - кнопка, которая принтит "Hello, World!". Также есть кнопка в контекстном меню, появляющемся при нажатии ПКМ, которое делает то же самое. Это выполняет требования всего первого уровня.

# 2й уровень - Таймеры
### Таймер Кодера
Данный таймер в левом нижнем углу является трэкером времени кодинга. Его также можно сбрасывать, нажав на него.

### Таймер Отдыха (Pomodoro)
Нажав на помидор в левом нижнем углу, начнётся таймер. Достигнув своего конца, появится сообщение, в котором написано, что пора отдыхать, после чего можно запускать таймер отдыха. Это работает циклично.

#  3й уровень - Tamagotchi
Данная фича позволяет вспомнить старые добрые времена и поухаживать за питомцем. Вкладка находится слева в toolbox-е, кнопка напоминает яйцо с лицом внутри. Показываются 3 статистики: Сытость, Энергия и Настроение из 100%. Питомца можно покормить. Это является отличным отвлечением от кодинга!
